# v4.13.1 — Ops status line (browser + Dash + terminal)

## Roadmap line
status_latest artifacts + ops_status CLI + optional Dash status tab

## What changed
- Weekly ops can now compute a stable **summary_line** from the report JSON and persist it into `ops_runs.summary_line`.
- Weekly ops can write `reports/status_latest.(json|txt|html)` with `--write-status-latest`.
- Added terminal helper: `python -m src.runners.ops_status` (supports `--open` and `--history N`).
- Added optional Dash status tab: `python -m src.ui.dash_status_app` (install via `.[dash]`).
- Added docs: `docs/OPS_STATUS.md`
- Version bump: 4.13.1

## Usage
```bash
python -m src.runners.weekly_ops --db ./journal/trader.db --channel MySignals --weeks 1 --out-dir ./reports --write-status-latest
python -m src.runners.ops_status --db ./journal/trader.db
```
