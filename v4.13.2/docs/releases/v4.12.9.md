# v4.12.9 — Batch eval (reconcile + thresholds)

## Roadmap line
windowed runs: signals → recon_v3 → threshold_eval → report

## What changed
- Added batch reconciliation runner: `src/runners/reconcile_batch_v3.py`
- Added batch threshold runner: `src/runners/threshold_batch_eval.py`
- Added pipeline runner: `src/runners/shadow_batch_pipeline.py`
- Added mechanisms doc: `docs/MECHANISMS_v4.12.9_batch_eval.md`

## Usage

### 3-step operator flow
```bash
python -m src.runners.reconcile_batch_v3 --db ./journal/trader.db --since ... --until ... --channel ...
python -m src.runners.threshold_batch_eval --db ./journal/trader.db --since ... --until ... --channel ...
python -m src.runners.report_pack --db ./journal/trader.db --since ... --until ... --channel ... --out-dir ./reports --out-prefix window
```

### One-shot pipeline
```bash
python -m src.runners.shadow_batch_pipeline --db ./journal/trader.db --since ... --until ... --channel ... --out-dir ./reports --out-prefix window
```

## Notes
- Batch runners are idempotent (skip existing unless `--overwrite`).
- Both can emit a JSON run-summary via `--emit-json <path>`.
