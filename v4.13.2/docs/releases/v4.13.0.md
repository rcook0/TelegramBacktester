# v4.13.0 — Weekly Ops

## Roadmap line
Operational wrapper: weekly reconcile + threshold eval + report, with rotation + audit tables.

## What changed
- Added ops persistence schema: `src/storage/sqlite_store_ops.py` (tables: `ops_runs`, `ops_artifacts`)
- Added weekly ops runner: `src/runners/weekly_ops.py`
- Added report rotation helper: `src/ops/rotation.py`
- Added module exec helper: `src/ops/exec.py`
- Added ops docs: `docs/OPS_WEEKLY.md`
- Bumped package version: 4.13.0

## Usage
```bash
python -m src.runners.weekly_ops --db ./journal/trader.db --channel MySignals --weeks 1 --out-dir ./reports
```

## Artifacts
- `reports/*` (csv/json/html/log + summaries)
- `ops_runs` + `ops_artifacts` in SQLite
