# v4.12.5 — P&L attribution (pips + base CCY)

## Roadmap line
trade_links → pnl_ccy attribution (account currency)

## What changed
- Added P&L attribution engine: `src/reconcile/pnl_attrib.py`
- Added runner: `src/runners/pnl_attrib.py`
- Writes `trade_links.pnl_ccy` and emits `shadow_snapshots(kind='pnl_attrib')`

## Mechanism (short)
- Infer contract sizing from cached `symbol_meta`:
  - `lotSize`, `pipSize`/`pipPosition`, `baseAsset`, `quoteAsset`
- Compute P&L in quote currency:
  - `pnl_quote = (exit-entry)*sign*lotSize*qty_lots`
  - `pnl_pips = ((exit-entry)*sign)/pipSize`
- Convert quote currency → account currency with a currency-graph built from:
  - `--rates-json` pairs (PAIR→mid), and
  - best-effort `quote` snapshots within ±`--rate-window-sec` of exit time

## Run (operator path)
```bash
python -m src.runners.pnl_attrib   --db ./journal/trader.db   --signal-idem-key <KEY>   --account-ccy USD   --rates-json '{"USDJPY":150.2,"EURUSD":1.08}'   --overwrite
```

## Artifacts (what to expect)
- tables:
  - `trade_links.pnl_ccy` populated (payload patched with `pnl_attrib`)
- snapshots:
  - `pnl_attrib`

## Why it matters
- Reconciliation, dashboards, and live scoring need P&L in account currency.

## Caveats
- If conversion pairs are missing from quote snapshots, supply them via `--rates-json` or capture those symbols as quotes.
